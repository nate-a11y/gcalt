# Sideline

> **Bring everyone closer to the game**

The open, reliable, and affordable youth sports team management platform.

## What is Sideline?

Sideline is a modern alternative to GameChanger, built for coaches, parents, and athletes who deserve better. We're creating a platform that prioritizes reliability, fair pricing, and putting users first.

## Features

- **Team Management** - Rosters, roles, and invites made simple
- **Smart Scheduling** - Games, practices, RSVPs, and calendar sync
- **Live Scorekeeping** - Real-time scores for baseball, softball, basketball, soccer, and more
- **Statistics** - Comprehensive stats tracking with season aggregations
- **Communication** - Team messaging, announcements, and notifications
- **Media** - Photo sharing, video uploads, and live streaming
- **AI Highlights** - Automatic clip detection and highlight reels

## Why Sideline?

| | GameChanger | Sideline |
|---|-------------|----------|
| Premium Price | $90/year (increasing) | $39/year |
| Customer Service | 1.6/5 rating | Community-first |
| Data Export | Limited | Full ownership |
| Reliability | Frequent issues | Multi-cloud, offline-capable |

## Tech Stack

- **Web**: Next.js, React, TypeScript, Tailwind CSS
- **Mobile**: React Native (iOS + Android)
- **Backend**: Node.js, PostgreSQL, Redis
- **Streaming**: Mux / Cloudflare Stream
- **Infrastructure**: Vercel, Fly.io, Cloudflare

## Getting Started
